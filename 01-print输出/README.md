## 1. 基础语法

```python
print("hello world")        # 输出字符串
print(666)                  # 输出数字
print(name)                 # 输出变量
print("a", "b", "c")        # 输出多个内容，默认空格隔开
print(10 + 20)              # 输出表达式结果
```

> 💡 `print()` 输出完默认会**自动换行**喵！

## 2. 进阶参数：sep 和 end

| 参数 | 作用 | 默认值 |
|------|------|--------|
| `sep` | 多个内容之间的分隔符 | 空格 `" "` |
| `end` | 输出结尾的字符 | 换行 `"\n"` |

```python
print("a", "b", "c", sep="-")   # a-b-c
print("hello", end="")          # 不换行
print("world")                  # helloworld
```

## 3. 格式化输出（三种方式）

| 方式 | 语法 | 例子 |
|------|------|------|
| `%` 格式化 | `"我是%s，今年%d岁" % (name, age)` | 老方法 |
| `format()` | `"我是{}，今年{}岁".format(name, age)` | 常用 |
| **f-string** | `f"我是{name}，今年{age}岁"` | ⭐ 最推荐 |

```python
print(f"明年我就{age + 1}岁了")    # f-string 里可以写表达式
print(f"成绩：{95.5:.2f}")         # 控制小数位数 → 95.50
```

> 🐍 **占位符速记**：`%s` 字符串、`%d` 整数、`%f` 小数

## 4. 小贴士

2. 📝 多个内容用逗号隔开，`sep` 和 `end` 可以一起用喵！
3. 🎨 用 `print` 的重复 `*` 和 `end` 可以画出各种图形喵！

## ⚠️ 注意事项（易踩的坑）

1. ⚠️ 字符串必须加引号：`print(hello)` 会被当成变量名，没定义就报 `NameError`；还要小心别把中英文引号混用喵！（`01_print基础使用.py`）
2. ⚠️ 字符串只能乘数字：`"哈哈" * 3` 是把字符串重复 3 遍，`"哈哈" * "3"` 字符串乘字符串会直接 `TypeError` 喵！（`01_print基础使用.py`）
3. ⚠️ `%` 占位符个数要对齐：`%s`/`%d` 和后面 `% (name, age)` 的元组必须一一对应，多一个少一个都报 `TypeError` 喵！（`03_print格式化输出.py`）
4. ⚠️ `end="\r"` 覆盖输出记得收尾：进度条最后要 `print("下载完成！")` 换行，不然下一行会压在进度条上喵！（`02_print的sep和end参数.py`）
5. ⚠️ 图形空格数要算准：等腰三角形用 `" " * (5 - i)` 控空格，菱形上半 `range(1, 6)`、下半 `range(4, 0, -1)` 必须衔接好，少一行图形就歪了喵！（`04_综合案例_打印图形.py`）
6. ⚠️ f-string 需要 Python 3.6+：`f"{name}"` 在老版本会语法报错，旧环境请用 `%` 或 `format()` 喵！（`03_print格式化输出.py`）
