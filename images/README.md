## ⚠️ 注意事项（易踩的坑）

1. ⚠️ 反斜杠路径要转义：Windows 路径 `D:\python.txt` 写进代码要写成 `"D:\\python.txt"` 或 `'D:/python.txt'`，直接写单个 `\` 会被当成转义符报错喵（12-文件操作笔记里用的就是正斜杠写法）。
2. ⚠️ 相对路径层级别数错：笔记在顶层文件夹用 `../images/` 就够，若笔记在子文件夹里要 `../../images/`，少写一层图片就裂开显示不出来喵。
3. ⚠️ 中文长文件名要一字不差：`微信图片_20260812174848_388_1.jpg` 这种名字最好复制粘贴，手打少一个字、多一个空格图片就引用失败喵。
4. ⚠️ 图片是二进制文件：别用文本模式 `open('r')` 去读 .jpg，要用 `'rb'` 二进制模式；笔记里引用图片走 Markdown 语法 `![说明](路径)` 就好，别用 Python 去 open 它喵。
5. ⚠️ 忘了关文件：读取图强调的「打开-读写-关闭」别漏最后一步，文件会一直占着资源；能用 `with open(...) as f:` 就让它自动关闭喵。
6. ⚠️ 新图入库忘了更新索引：README 小贴士说了，图没被任何笔记引用就要清理；反过来新图放进来了也要及时登记进「图片清单」，不然变成没人管的孤儿图喵。
