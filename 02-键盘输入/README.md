## 1. 基础语法

```python
name = input("请输入你的名字：")
print(name)
```

- `input("提示语")` 会先在屏幕打印提示语，然后等待键盘输入
- 按 **回车** 确认输入
- ⚠️ **重点**：`input()` 接收到的内容**永远是字符串类型**（str）！

```python
age = input("请输入年龄：")
print(type(age))   # <class 'str'>
```

## 2. 类型转换

| 函数 | 作用 | 例子 |
|------|------|------|
| `int(x)` | 转成整数 | `int("18")` → `18` |
| `float(x)` | 转成小数 | `float("1.75")` → `1.75` |
| `str(x)` | 转成字符串 | `str(18)` → `"18"` |

```python
num1 = int(input("请输入第一个整数："))
num2 = int(input("请输入第二个整数："))
print(num1 + num2)          # 数学运算
```

> 💡 也可以一步到位：`number = int(input("请输入数字："))`

## 3. 注意事项

1. 🐍 输入的内容默认是字符串，**做运算前必须先转换类型**
2. 🔢 输入了无法转换的内容（如 `"abc"`）会报 `ValueError`
3. 📝 转换写法：`int(字符串)`、`float(字符串)`

## ⚠️ 注意事项（易踩的坑）

1. ⚠️ **忘记转换类型就做运算**：`num1 + num2` 在没转 `int`/`float` 前是字符串拼接（`"12" + "34"` → `"1234"`），结果会吓主人一跳喵！参考 `02_输入类型转换.py`
2. ⚠️ **输入无法转换的内容会报错**：`int("abc")`、`float("你好")` 都会抛 `ValueError`，输入前要保证是数字喵！
3. ⚠️ **想输入小数却用 `int()`**：`int("1.75")` 会直接报错，要支持小数必须用 `float()`，就像加法计算器那样喵！参考 `03_综合案例_加法计算器.py`
4. ⚠️ **转换后忘记重新赋值**：`int(num1)` 只是算了个新值，必须写回 `num1 = int(num1)` 才生效，不然就白转喵！参考 `02_输入类型转换.py`
5. ⚠️ **`input()` 里忘写提示语**：程序会一声不吭地傻等输入，主人根本不知道要敲什么喵！养成写提示语的好习惯，参考 `01_input基础使用.py`
