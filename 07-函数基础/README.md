## 🔍 内容说明

### 1. 定义与调用（`函数语法及应用.py`）

```python
def add(x, y):
    print(f"{x}+{y}={x + y}")
    return x + y

a = add(10, 20)    # 调用函数，接收返回值
```

### 2. 返回值（`01_函数返回值.py` / `返回值none.py`）

```python
def total(x, y):
    return x + y

def check(num):        # 没有 return → 返回 None
    if num > 0:
        print("right")
    else:
        print("wrong")
```

> 💡 **None 的应用**：没有 `return` 的函数默认返回 `None`，
> 可以用 `if not 函数()` 判断结果是否为 None 喵！

### 3. 变量作用域（`函数的变量作用域.py` / `内部定义全局变量.py`）

- **局部变量**：函数内部定义，只能在函数内用
- **全局变量**：函数外部定义，全局可用
- **`global`**：在函数内声明，即可修改/定义全局变量

```python
def print_b():
    global number    # 声明 number 是全局变量
    number = 100
    return number
```

> ⚠️ 局部变量在函数外访问会报 `NameError` 喵！

### 4. 嵌套调用（`函数的嵌套调用.py`）

```python
def print_c():
    print("-----c-----")
    print_a()        # 函数里调用其他函数
    print_b()
```

### 5. 函数说明文档（`函数说明文档.py`）

用多行注释 `"""..."""` 写在函数第一行，就是函数的「说明书」喵！

```python
def add(a, b):
    """
    这是一个将两数字a，b相加的函数
    a、b为输入的两数字
    return 相加结果
    """
    return a + b
```

## ⚠️ 注意事项（易踩的坑）

1. ⚠️ **局部变量在函数外访问必报错**：`函数的变量作用域.py` 里 `print(num)` 直接 `NameError: name 'num' is not defined`，因为 num 是函数内的局部变量，出了函数就不存在喵！
2. ⚠️ **没有 return ≠ 什么都没返回**：`01_函数返回值.py` 里 `check()` 没写 return，调用后拿到的其实是 `None`，用 `type()` 一看是 `NoneType`，别把它当数字继续运算喵！
3. ⚠️ **多个 `if` 不互斥会重复输出**：`01_案例/检查核酸.py` 里用了两个独立的 `if`，体温 30° 时既打印「体温正常」又会走进第二个 if 的 `else` 打印「疑似阳性」，应该改成 `elif` 喵！
4. ⚠️ **`int(input())` 直接转数字会崩**：输入「abc」或空内容会抛 `ValueError`，`模拟ATM.py` 用 `try/except` 兜住，但 `检查核酸.py` 的 `int(temp)` 没保护，学 ATM 记得给输入加 try 喵！
5. ⚠️ **改全局变量忘了 `global` 声明**：`内部定义全局变量.py` 和 `模拟ATM.py` 里改 `number`、`save_money` 之前都先 `global` 声明，忘了声明会在函数内新建一个局部变量，外面根本改不到喵！
