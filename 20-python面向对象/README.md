## 🔍 学习内容说明

### 1~3. 类、对象、成员方法与构造方法

```python
class Student:
    def __init__(self, name, age, hobby):   # 构造方法
        self.name = name
        self.age = age
        self.hobby = hobby

    def say_hello(self):                     # 成员方法
        print(f"我是{self.name}")

stu = Student("richenyv", 18, "yuki")
```

- **类**（class）是设计图纸，**对象**是根据图纸造出来的实例
- `__init__` 构造方法：创建对象时自动执行，用来初始化成员变量
- 成员方法第一个参数必须是 `self`（指向对象自己）喵！

### 4. 其他内置方法（魔术方法）

| 方法 | 作用 |
|------|------|
| `__str__` | `print(对象)` 时调用，返回字符串 |
| `__lt__` / `__le__` | `对象 < 对象` / `对象 <= 对象` 比较时调用 |
| `__eq__` | `对象 == 对象` 比较时调用 |

> ⚠️ 不设置这些方法时，比较会按**对象地址**进行喵！

### 5. 封装（私有成员）

- 成员名以 `__` 开头（两个下划线）就是**私有成员**，类外不能直接访问
- 提供公共方法间接访问，实现「封装」喵！

### 6~7. 继承、复写与父类调用

```python
class Phone_2(Phone_1, NFC):        # 多继承
    def __init__(self, ...):
        Phone_1.__init__(self, ...) # 手动调用父类构造
    def call_by_5g(self):           # 新方法
        ...
```

- 子类自动拥有父类的成员，可以**多继承**（逗号分隔）
- 子类可以**复写**（override）父类方法
- 用 `父类名.方法(self, ...)` 或 `super().方法(...)` 调用父类成员喵！

### 8. 类型注解

```python
age: int = 18                          # 变量注解
def add(a: int, b: int) -> int: ...    # 函数注解
from typing import Union
x: Union[int, str] = 1                 # Union 联合类型
```

> 💡 类型注解**不强制**，但能让代码更清晰、IDE 提示更友好喵！

### 9. 多态

同一个方法在不同类里有不同表现，父类定义接口、子类各自实现喵！

## ⚠️ 注意事项（易踩的坑）

1. ⚠️ Windows 路径记得加 `r` 前缀：`File_define.py` 和 `数据分析案例.py` 里硬编码了 `r"D:\PythonProject\14-json原始数据\..."` 绝对路径，忘写 `r` 时 `\t`、`\n` 会被转义；而且换台电脑目录不同就会 FileNotFoundError 喵！
2. ⚠️ 私有成员 `__x` 类外直接访问会报 AttributeError（`登记表_5.py` 的 `__native_place`、手机案例的 `__is_5g_enable` 都是），必须通过公开方法间接访问喵！
3. ⚠️ 类型注解不强制！`1-变量的类型注解.py` 里 `var_4: int = "richenyv"` 照样能跑，注解只是给 IDE 看的提示、不是类型检查，别指望它帮你抓类型错误喵！
4. ⚠️ 不写魔术方法时对象比较的是「地址」：`登记表_4.py` 注释里提醒过，两个 Student 直接 `==` 永远 False，想按年龄等字段比较必须自己写 `__eq__` 喵！
5. ⚠️ Python 的「抽象类」是纸老虎：`File_define.py` 里 `read_data()` 只是 `pass`，子类忘了复写也不会报错，调用后悄悄返回 None，静默出错超难排查喵！
6. ⚠️ 读文件要指定编码并注意表头/格式：`TextReader` 用计数器跳过表头、`JsonReader` 靠 `json.loads` 解析（读的其实是 `.txt` 扩展名的 JSON 数据），不指定 `encoding="utf-8"` 或内容不合法就会乱码/抛 JSONDecodeError 喵！
