## 🔍 数据说明

### 1. 新冠数据（`covid19_2022_*.txt`）

每个国家的 txt 文件里存的是 **JSON 格式**的数据，结构大致如下：

```json
{
  "data": {
    "name": "日本",
    "日期": [...],
    "num": {
      "确诊": [...],
      "新增": [...],
      "死亡": [...]
    }
  }
}
```

> 💡 文件扩展名虽然是 `.txt`，但内容是一行行的 JSON，
> 用 `json.loads(f.read())` 就能读成 Python 字典喵！

### 2. 三国汇总（`totallynum.txt`）

三国数据汇总在一个 JSON 里，结构为：

```json
{
  "num_usa": {"确诊": [...], "新增": [...], "死亡": [...]},
  "num_jp":  {...},
  "num_pi":  {...}
}
```

### 3. 各国 GDP 数据（`各国GDP_1960-2026.txt`）

**CSV 格式**（逗号分隔），第一行是表头，后面每行一个国家一年的数据：

```csv
year,GDP,rate,country
1960,5433,2.5,美国
1961,5834,2.6,美国
```

| 字段 | 含义 |
|------|------|
| `year` | 年份（1960~2026） |
| `GDP` | GDP 数值（亿美元） |
| `rate` | 增长率（%） |
| `country` | 国家名 |
