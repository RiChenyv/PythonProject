## 🔍 数据说明

### 1. 新冠数据（`covid19_2022_*.txt`）

每个国家的 txt 文件里存的是 **JSON 格式**的数据，结构大致如下：

```json
{
  "data": {
    "name": "日本",
    "日期": [...],
    "num": {
      "确诊": [...],
      "新增": [...],
      "死亡": [...]
    }
  }
}
```

> 💡 文件扩展名虽然是 `.txt`，但内容是一行行的 JSON，
> 用 `json.loads(f.read())` 就能读成 Python 字典喵！

### 2. 三国汇总（`totallynum.txt`）

三国数据汇总在一个 JSON 里，结构为：

```json
{
  "num_usa": {"确诊": [...], "新增": [...], "死亡": [...]},
  "num_jp":  {...},
  "num_pi":  {...}
}
```

### 3. 各国 GDP 数据（`各国GDP_1960-2026.txt`）

**CSV 格式**（逗号分隔），第一行是表头，后面每行一个国家一年的数据：

```csv
year,GDP,rate,country
1960,5433,2.5,美国
1961,5834,2.6,美国
```

| 字段 | 含义 |
|------|------|
| `year` | 年份（1960~2026） |
| `GDP` | GDP 数值（亿美元） |
| `rate` | 增长率（%） |
| `country` | 国家名 |

### 4. 销售数据（`2026年1、2月销售数据.txt`）

| 文件 | 格式 | 字段 |
|------|------|------|
| `2026年1月销售数据.txt` | CSV（逗号分隔，首行表头） | 日期 / 订单id / 销售额 / 销售省份 |
| `2026年2月销售数据.txt` | JSON（列表套字典） | 日期 / 订单id / 销售额 / 销售省份 |

> 💡 同一份业务数据，用两种格式存放，
> 正好用来练习「**同一个接口，不同格式的读取器**」喵！

### 5. 搜索引擎日志（`搜索引擎日志.txt`）

**制表符 `\t` 分隔**，每行一条搜索记录，共 3 列：

```
2026-07-25 10:15:14	mysql	192.168.2.189
```

| 列 | 含义 |
|----|------|
| 第 1 列 | 搜索时间（`日期 时:分:秒`，小时在第 11~13 位） |
| 第 2 列 | 搜索词 |
| 第 3 列 | 用户 IP |

> 💡 被 [`22-pyspark实战/实战案例/Case_03.py`](../22-pyspark实战/README.md) 用来做
> **热门时段 / 热门搜索词 / 各词最热时段**分析喵！

## ⚠️ 注意事项（易踩的坑）

1. ⚠️ 扩展名是 `.txt` 别当纯文本硬读——内容是 JSON/CSV，必须用 `json.loads()` / `csv.reader()` 解析，不然只会拿到一堆字符串喵。
2. ⚠️ `totallynum.txt` 里只有数字、没有「日期」——x 轴日期要另外从 `covid19_2022_*.txt` 的「日期」数组取，别以为汇总文件啥都有喵。
3. ⚠️ 中文数据文件必须指定 `encoding="utf-8"` 读取——实测用系统默认 GBK 打开 `totallynum.txt`，「确诊」会乱码成「纭瘖」喵。
4. ⚠️ `csv` 读出来的全是字符串——GDP 的 `year`/`rate` 要先 `int()`/`float()` 才能算数；`rate` 有负值，别写死「全为正」的逻辑。
5. ⚠️ 销售 CSV 的日期不连续——1 月缺了 `01-04`、`01-14` 等日期，按日统计别默认每天都有一行订单喵。
6. ⚠️ JSON 的中文键名一个都不能错——`确诊/新增/死亡`、`日期/订单id/销售额/销售省份`，写错一个立刻 KeyError；目录名带中文「原始数据」，绝对路径里的反斜杠和转义也要小心喵。
7. ⚠️ 搜索引擎日志用 `\t` 分隔不是逗号——`split(",")` 拆不出 3 列，必须 `split("\t")`；取小时用 `[11:13]`（从第 11 位开始取 2 位）别数错位置喵。
8. ⚠️ `saveAsTextFile` 的输出目录要提前清理——`搜索引擎json数据处理返回/` 已存在时再次运行 `Case_03.py` 会报错，先删目录再跑喵！
