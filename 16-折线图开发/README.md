## 🔍 内容说明

### 主程序（`折线图开发.py`）

数据流：

```
读取 txt → json.loads 解析 → 取出日期/确诊/新增/死亡 → Line 绘图 → Tab 组合 → render
```

**第一部分：各国独立折线图**
- 用一个字典存三国路径，`for` 循环**批量处理**
- 每个国家一张 `Line` 图：新增 / 确诊 / 死亡 三条线
- `set_global_opts` 设置标题、图例、工具箱

**第二部分：三国对比图**
- 读取 `totallynum.txt` 汇总数据
- 用「指标 → 标题」字典 + 双重循环，确诊 / 新增 / 死亡 各画一张三国对比图

**第三部分：Tab 按钮切换**
- 用 `Tab()` 把 6 张图装进一个页面，点按钮切换喵！

### 生成结果（`render.html`）

共包含 **6 张图**，浏览器打开即可交互查看：

| # | 图表标题 | 内容 |
|---|----------|------|
| 1~3 | 美国 / 日本 / 印度 2022年度新冠数据统计 | 各国「新增 / 确诊 / 死亡」三条线 |
| 4~6 | 美、日、印三国新冠确诊 / 新增 / 死亡数据统计 | 三国同图对比 |

支持 **Tab 按钮切换**、图表缩放、工具箱导出图片喵～

## ⚠️ 注意事项（易踩的坑）

1. ⚠️ 路径转义：Windows 路径里 `\P`、`\1` 会被当成转义字符，必须写正斜杠 `D:/...` 或加 `r` 前缀的原始字符串——代码里两种写法都有，别混用喵
2. ⚠️ 忘记 `encoding="utf-8"`：Windows 默认用 GBK 读中文 txt，不指定 utf-8 直接报 `UnicodeDecodeError` 喵
3. ⚠️ `json.loads(...)["data"]` 直接下标取键：JSON 结构一变化（少了 `data` 键）立刻抛 `KeyError`，先用 `in` 判断更稳喵
4. ⚠️ 重复读取与重复渲染：`totallynum.txt` 在三国循环里被读了 3 遍，`tab.render()` 也调了 3 次，结果一样但白费功夫，挪到循环外只做一次就好喵
5. ⚠️ 硬编码绝对路径 `D:/PythonProject/...`：换台电脑、换个目录就找不到文件，改成相对路径或 `Path(__file__)` 更保险喵
6. ⚠️ `render.html` 依赖 CDN：图表脚本从 `assets.pyecharts.org` 在线加载，断网打开会是空白，需要联网看图喵
