## 🔍 内容说明

### 1. 定义与调用（`函数语法及应用.py`）

```python
def add(x, y):
    print(f"{x}+{y}={x + y}")
    return x + y

a = add(10, 20)    # 调用函数，接收返回值
```

### 2. 返回值（`01_函数返回值.py` / `返回值none.py`）

```python
def total(x, y):
    return x + y

def check(num):        # 没有 return → 返回 None
    if num > 0:
        print("right")
    else:
        print("wrong")
```

> 💡 **None 的应用**：没有 `return` 的函数默认返回 `None`，
> 可以用 `if not 函数()` 判断结果是否为 None 喵！

### 3. 变量作用域（`函数的变量作用域.py` / `内部定义全局变量.py`）

- **局部变量**：函数内部定义，只能在函数内用
- **全局变量**：函数外部定义，全局可用
- **`global`**：在函数内声明，即可修改/定义全局变量

```python
def print_b():
    global number    # 声明 number 是全局变量
    number = 100
    return number
```

> ⚠️ 局部变量在函数外访问会报 `NameError` 喵！

### 4. 嵌套调用（`函数的嵌套调用.py`）

```python
def print_c():
    print("-----c-----")
    print_a()        # 函数里调用其他函数
    print_b()
```

### 5. 函数说明文档（`函数说明文档.py`）

用多行注释 `"""..."""` 写在函数第一行，就是函数的「说明书」喵！

```python
def add(a, b):
    """
    这是一个将两数字a，b相加的函数
    a、b为输入的两数字
    return 相加结果
    """
    return a + b
```
