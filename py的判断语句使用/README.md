## 1. if 判断语法总览

### 单分支 if

```python
if 条件:
    条件成立时执行的代码
```

### 双分支 if-else

```python
if 条件:
    条件成立执行的代码
else:
    条件不成立执行的代码
```

### 多分支 if-elif-else

```python
if 条件1:
    代码1
elif 条件2:
    代码2
elif 条件3:
    代码3
else:
    都不满足时执行的代码
```

> ⚠️ **从上往下依次匹配，命中一个就结束**，后面的分支不会再判断喵！

### 嵌套 if

```python
if 外层条件:
    if 内层条件:
        内层代码
    else:
        内层另一段代码
else:
    外层另一段代码
```

> ⚠️ **缩进决定层级**！内层 if 必须缩进到外层 if 的代码块里喵！

## 2. 布尔类型（True / False）

- 只有两个值：`True`（真）、`False`（假），首字母必须大写
- 判断语句的运算结果就是布尔类型
- `bool()` 可以转换：数字 `0` 为 False，非 0 为 True；空字符串为 False，非空为 True

## 3. 比较运算符

| 运算符 | 含义 | 例子 |
|--------|------|------|
| `==` | 等于 | `10 == 10` → True |
| `!=` | 不等于 | `10 != 20` → True |
| `>` | 大于 | `10 > 20` → False |
| `<` | 小于 | `10 < 20` → True |
| `>=` | 大于等于 | `10 >= 10` → True |
| `<=` | 小于等于 | `20 <= 10` → False |

## 4. 逻辑运算符

| 运算符 | 含义 | 记忆 |
|--------|------|------|
| `and` | 与（两边都真才真） | 一假全假 |
| `or` | 或（一边真就是真） | 一真全真 |
| `not` | 非（取反） | 真变假，假变真 |

```python
# 判断闰年的经典写法
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print("是闰年")
```

## 💡 小贴士

1. 🐍 Python 用**缩进**（一般 4 个空格）表示代码块，不要用 Tab 混搭喵！
2. 📝 比较运算符 `==` 是判断相等，赋值是 `=`，别搞混喵！
3. 🎯 多条件判断优先用 `if-elif-else`，比写一堆 `if` 更高效喵！
